열린족보이야기

아담부터 예수 그리스도에 이르는 성경의 전체 계보를
자유로운 확대/축소와 함께 탐색하고 연구하는 시각화 플랫폼

✨ 메시아 직계선 강조
📝 인물별 개인 연구 메모
📐 맞춤형 지파 필터
※ 위 버튼을 클릭하면 5분 동안 실제 프로그램을 웹에서 미리 체험해 보실 수 있습니다.

⚠️ 프로그램 설치 시 보안 경고 해결 안내

본 프로그램은 정식 서버에서 직접 빌드된 안전한 앱입니다. 대기업의 고가 유료 보안 서명을 거치지 않은 순수 배포용 파일이므로 운영체제가 차단 경고를 표시할 수 있으나 안심하고 실행하셔도 됩니다.

🪟 Windows 설치 안내 (SmartScreen 우회)

  1. 다운로드받은 msi 파일을 실행합니다.
  2. "Windows의 PC 보호" 파란색 차단 창이 뜨면 당황하지 마시고 창 본문의 [추가 정보] 링크를 클릭합니다.
  3. 그럼 화면 우측 하단에 나타나는 [실행](Run anyway) 버튼을 누르면 정상적으로 설치가 시작됩니다!

🍎 macOS 설치 안내 (Gatekeeper 우회)

  1. 다운로드받은 dmg 파일을 열고 프로그램 아이콘을 [응용 프로그램](Applications) 폴더로 끌어다 놓습니다.
  2. 응용 프로그램 폴더로 이동하여 해당 앱을 그냥 더블클릭하지 마시고, 마우스 [우클릭](또는 Control + 클릭)을 합니다.
  3. 메뉴에서 [열기]를 선택한 뒤, 팝업 경고창이 나타나면 아래쪽의 [열기] 버튼을 누르면 즉시 실행됩니다. (최초 1회만 설정하시면 됩니다.)
  4. 또는 맥의 [시스템 설정] ➡️ [개인정보 보호 및 보안] 메뉴의 하단에서 [확인 없이 열기] 버튼을 누르셔도 실행 가능합니다.
🔒 위 설치 안내를 읽고 [확인] 버튼을 클릭하시면 다운로드 버튼이 활성화됩니다.

📖 성경 족보 사용법 및 안내 가이드

💡 이 프로그램은 개별 로컬 저장 방식으로 운영됩니다.
  • 로컬 데이터 저장: 모든 데이터는 사용자의 개인 컴퓨터에 안전하게 저장됩니다.
  • 데이터 공유 지원: 동일한 ID로 로그인 시 여러 기기에서 데이터를 함께 공유할 수 있습니다.

🔍 기본 조작 및 인물/사건 검색

  • 화면 조작: 마우스 드래그로 화면 이동, 휠 또는 하단 컨트롤러( / ) 버튼으로 확대/축소할 수 있습니다.
  • 기본 홈(원점): 하단 버튼을 누르면 첫 화면(100% 비율)으로 돌아옵니다.
  • 검색창: 화면 상단 검색창에 이름, 장소, 사건을 입력하면 해당 인물이나 마커로 즉시 이동하며 하이라이트됩니다.

📺 강의 및 설교 프레젠테이션 활용

성경을 가르치거나 설교할 때 시각 자료로 아주 유용하게 사용할 수 있습니다. 빔 프로젝터나 화면 공유를 통해 인물 간의 관계선(대조) 및 계보 흐름을 한눈에 명확하게 보여줄 수 있습니다.

🎛️ 계보 필터 및 묵상 메모 작성

  • 계보 필터링: 하단 조절기() 버튼을 누르면 특정 계보(가인, 함, 마리아 계보 등)만 활성화하여 볼 수 있습니다.
  • 메모 연동: 필터를 체크하여 활성화하는 순간, 우측에 해당 계보에 관한 개인 묵상 메모와 링크를 기록할 수 있는 사이드바 패널이 자동으로 활성화됩니다.
