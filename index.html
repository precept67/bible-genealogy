ℹ️ 기기 간 메모 동기화 안내
2대의 컴퓨터(기기) 간 메모 내역을 상호 연동하여 사용하기 위한 로그인 창입니다. 양쪽 기기에서 동일한 아이디로 로그인하시면 기록한 연구 자료가 실시간 공유됩니다.

⚠️ 프로그램 설치 시 보안 경고 해결 안내

본 프로그램은 정식 서버에서 직접 빌드된 안전한 앱입니다. 대기업의 고가 유료 보안 서명을 거치지 않은 순수 배포용 파일이므로 운영체제가 차단 경고를 표시할 수 있으나 안심하고 실행하셔도 됩니다.

🪟 Windows 설치 안내 (SmartScreen 우회)

  1. 다운로드받은 msi 파일을 실행합니다.
  2. "Windows의 PC 보호" 파란색 차단 창이 뜨면 당황하지 마시고 창 본문의 [추가 정보] 링크를 클릭합니다.
  3. 그럼 화면 우측 하단에 나타나는 [실행](Run anyway) 버튼을 누르면 정상적으로 설치가 시작됩니다!

🍎 macOS 설치 안내 (Gatekeeper 우회)

  1. 다운로드받은 dmg 파일을 열고 프로그램 아이콘을 [응용 프로그램](Applications) 폴더로 끌어다 놓습니다.
  2. 응용 프로그램 폴더로 이동하여 해당 앱을 그냥 더블클릭하지 마시고, 마우스 [우클릭](또는 Control + 클릭)을 합니다.
  3. 메뉴에서 [열기]를 선택한 뒤, 팝업 경고창이 나타나면 아래쪽의 [열기] 버튼을 누르면 즉시 실행됩니다. (최초 1회만 설정하시면 됩니다.)
  4. 또는 맥의 [시스템 설정] ➡️ [개인정보 보호 및 보안] 메뉴의 하단에서 [확인 없이 열기] 버튼을 누르셔도 실행 가능합니다.

📖

성경 족보 사용법 및 기능 가이드

Bible Genealogy User & Feature Guide
💡 로컬 독립 저장 및 안전한 데이터 보존
  • 개별 로컬 영구 저장: 모든 편집 작업(인물, 사건, 장소, 메모, 연결선 등)은 사용자 PC 로컬 스토리지에 즉시 안전하게 자동 보존됩니다.
  • 멀티 디바이스 연동: 동일한 라이선스 키/계정으로 로그인 시 iCloud 및 멀티 기기 간 데이터 공유를 지원합니다.

🔍 1. 화면 탐색 및 통합 검색

  • 화면 이동 (Pan): 마우스 좌클릭 후 드래그하거나 트랙패드 두 손가락으로 캔버스를 상하좌우 자유롭게 이동합니다.
  • 확대/축소 (Zoom): 마우스 휠 스크롤, 트랙패드 핀치(Pinch), 또는 하단 컨트롤러의 + / - 버튼을 사용합니다.
  • 100% 원점 화면 리셋: 단축키 ⌘0 (Windows: Ctrl+0) 또는 하단 홈(🏠) 버튼을 누르면 첫 기본 크기(100%)로 돌아옵니다.
  • 통합 검색창: 상단 메뉴바 검색창에 인물 이름, 주요 사건, 지명/장소를 입력하면 해당 위치로 즉시 포커스 이동 및 하이라이트됩니다.

🔓 2. 편집 모드 및 상자(Box) 추가

  • 편집 모드 전환: 상단 메뉴 편집 (Edit) ➡️ 🔓 편집 모드 전환 또는 단축키 ⇧⌘E(Shift+Cmd+E)를 누릅니다. 편집 모드 진입 시 배경에 미세한 정밀 방안 격자가 표시되어 정렬을 돕습니다.
  • 👤 인물 카드 (Person): 새 인물을 추가하고 원하는 위치로 드래그 배치합니다. 인물 카드를 더블클릭하면 생몰년, 부모/배우자 관계, 성경 구절 등을 상세 편집할 수 있습니다.
  • 📜 주요 사건 (Event): 역사적 사건 상자를 추가하여 연대표 및 타임라인에 배치합니다.
  • 📍 장소/지명 (Location): 성경 속 도시, 산, 지역 상자를 생성하여 지리적 맥락을 연결합니다.
  • 📝 메모 상자 (Note Box): 자유로운 해설, 묵상 메모, 성경 구절 텍스트 상자를 원하는 곳에 배치합니다.
  • 🔷 영역 다각형 (Region): 다각형 영역을 그려 지파별 영토, 시대적 공간 등을 시각적으로 구분합니다.

📋 3. 상자 복사, 붙여넣기 및 즉시 복제

  • 복사 (⌘C) & 붙여넣기 (⌘V): 인물, 사건, 장소, 메모 상자, 영역 다각형 등 복사할 상자를 클릭하여 선택한 후 ⌘C를 누르고, 원하는 시점에 ⌘V를 누르면 새로운 고유 ID가 부여된 복사본이 생성됩니다.
  • 즉시 복제 (⌘D): 상자를 선택한 상태에서 ⌘D를 누르면 그 자리에 즉시 복제본(+30px)이 생성됩니다.
  • 상단 편집 (Edit) 메뉴의 복사 (Copy), 붙여넣기 (Paste), 박스 즉시 복제 (Duplicate Box) 메뉴 항목으로도 동일하게 조작할 수 있습니다.

✏️ 4. 인물 이름 변경 및 고유 ID 자동 동기화

  • 인물 정보 수정 모달에서 이름을 수정하면 영문/한글 기반 고유 ID가 실시간으로 자동 제안 및 수정 가능하도록 지원됩니다.
  • ID가 변경되면 부모·배우자 관계, 스승·선지자 연결, 관련 사건/장소, 커스텀 시각 연결선, 굴절점, 개인 메모 등 모든 연관 데이터가 누락 없이 완벽하게 자동 갱신됩니다.

🎛️ 5. 레이어(Layers) 실시간 제어 및 시각화

  • 상단 레이어 (Layers) 메뉴에서 인물 족보(👤), 주요 사건(📜), 장소/지명(📍), 영역 다각형(🔷), 선지자 계보(👑) 레이어를 원클릭으로 켜고 끌 수 있습니다.
  • 현재 화면에 표시 중인 활성 레이어는 메뉴 항목 옆에 실시간 체크마크(✓)로 표시됩니다.
  • 자유 연결선 & 굴절점: 상자 간 마우스 드래그로 관계선을 생성하고, 선을 더블클릭하여 굴절점(Bend points) 및 스타일(색상/굵기/점선)을 지정할 수 있습니다.

💾 6. 데이터 백업 및 복원 (JSON Backup & Restore)

  • 상단 파일 (File) ➡️ 연구 메모 백업 (JSON 저장) 메뉴를 통해 전체 족보 데이터 및 연구 노트를 파일로 안전하게 백업할 수 있습니다.
  • 연구 메모 복원 (JSON 불러오기)을 통해 다른 기기나 백업 시점의 데이터를 손쉽게 복원할 수 있습니다.

⌨️ 7. 주요 단축키 안내표 (Keyboard Shortcuts)

단축키 (Mac / Win) 기능 및 동작 설명
⇧⌘E / Shift+Ctrl+E 편집 모드 전환 (잠금 해제 / 편집 종료)
⌘C / Ctrl+C 선택한 상자(인물/사건/장소/메모/영역) 복사
⌘V / Ctrl+V 복사된 상자를 새 고유 ID로 붙여넣기
⌘D / Ctrl+D 선택한 상자 즉시 복제 (Duplicate)
⌘Z / Ctrl+Z 실행 취소 (Undo)
⇧⌘Z / Ctrl+Y 다시 실행 (Redo)
⌘0 / Ctrl+0 100% 기본 크기 화면 리셋
Esc 팝업 모달 닫기 / 상자 선택 해제
